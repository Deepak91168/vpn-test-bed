# OpenVPN experiments

Edit `run.json`, then run `sudo ./runner/vpnlab run openvpn` from the V2 root. `sessions: N` is the **total** number of sequential sessions for the selected modes. The runner divides N as evenly as possible and shuffles their order by default. For all eight modes, `sessions: 24` gives 3 each; `sessions: 50` gives six modes 6 and two modes 7. Each selected mode must receive at least one session, so N must be at least the number of selected modes. The seed determines any extra-session assignments, order, website draws, and delays; `schedule.csv` and `configuration_summary.csv` show the resulting plan and counts. The config also sets three random web visits by default, optional `reneg_sec`, and minimum connected `session_seconds`. With `mixed_rekeys: true`, an all-eight mixed run with no explicit `reneg_sec` balances 0/1/2 **target** renewals per mode and uses a 12-second tunnel hold if `session_seconds` is zero. Session metadata records the observed renewal count, which can differ from the target. CLI flags override the config for one run. See the root README for commands and result interpretation.
